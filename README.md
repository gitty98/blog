# PHP Blog Website

A simple blog application built using PHP, MySQL, HTML, CSS and Bootstrap.

## Features
- User registration and login
- Session-based authentication
- Create blog articles
- Edit existing articles
- Delete articles
- Upload article images
- MySQL database integration

## Technologies
- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP

## Installation

1. Clone or download this repository.
2. Place the `blog` folder inside XAMPP's `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create a database named `blog`.
6. Import `blog.sql`.
7. Check the database settings in `connection.php`.
8. Visit `http://localhost/blog/`.
